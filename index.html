Sobre

O Robo Ofertas TH é um programa de uso pessoal que roda no computador do dono do canal Ofertas TH. Ele monta vídeos curtos sobre promoções de tecnologia e utilidades para casa e os publica no canal do YouTube do próprio dono, usando a YouTube Data API.

O app não é oferecido ao público: o único usuário é o dono do canal, que autoriza o acesso à própria conta.

Canais do Ofertas TH: Telegram · YouTube

Política de Privacidade

Atualizada em 2 de novembro de 2026.

Que dados o app acessa

Com a autorização do usuário pelo Google (OAuth), o app usa as permissões:

  • youtube.upload: enviar vídeos para o canal autorizado;
  • youtube.readonly: ler o nome do canal e o número de inscritos, para confirmar que o canal certo foi conectado.

O app não lê e-mails, contatos, comentários, histórico de visualização nem qualquer outro dado da conta Google.

Como os dados são usados e guardados

  • Os tokens de acesso do Google ficam guardados apenas no computador do dono, em um arquivo local. Não são enviados a nenhum servidor nosso nem a terceiros.
  • O nome do canal e o número de inscritos são usados só para mostrar ao dono qual canal está conectado.
  • O app não vende, não compartilha e não usa dados da conta para publicidade.
  • O app não guarda dados de outras pessoas nem de espectadores do canal.

Serviços do Google e do YouTube

O app usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. Os dados tratados pelo Google seguem a Política de Privacidade do Google.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como cancelar o acesso

Você pode tirar o acesso do app a qualquer momento em myaccount.google.com/permissions. Ao fazer isso, o token guardado no computador deixa de funcionar. Para apagar os dados locais, basta excluir o arquivo de token da pasta do app.
